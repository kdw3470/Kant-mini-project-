# 미니 프로젝트: 터미널 쇼핑몰 장바구니

터미널 환경에서 동작하는 온라인 쇼핑몰 장바구니 프로그램입니다. 객체 지향 프로그래밍(OOP)을 기반으로 설계되었으며, 상품 조회, 장바구니 담기/빼기, 조건별 할인 쿠폰 적용 및 재고 차감 결제 기능을 제공합니다.

## 🌟 주요 기능

1. **상품 목록 (1번)**: 전체 상품의 이름, 가격, 현재 재고를 출력합니다.
2. **장바구니 담기/빼기 (2번, 3번)**: 상품 번호와 수량을 입력받아 장바구니에 담거나 뺍니다. 품절 및 재고 부족 상황을 예외 처리하여 안내 메시지를 출력합니다.
3. **장바구니 확인 (4번)**: 장바구니에 담긴 내역, 상품 합계, 적용된 쿠폰의 할인 금액, 최종 결제 금액을 명세서 형태로 출력합니다.
4. **쿠폰 적용 (5번)**: 보유한 쿠폰 목록 중 하나를 선택하여 결제 시 할인을 적용합니다. 다형성을 통해 각 쿠폰의 할인 조건이 다르게 계산됩니다.
5. **결제 및 재고 차감 (6번)**: 장바구니에 담긴 수량만큼 실제 상품 객체의 재고를 감소시키고, 장바구니 내역을 초기화합니다.

## 🛠 데이터 관리 구조

이 프로그램은 효율적인 상태 관리를 위해 파이썬의 기본 자료구조인 리스트(`List`)와 딕셔너리(`Dictionary`)를 적극 활용합니다.

* **상품 관리 (`product_list`)**
  * `Product` 객체들을 담고 있는 **리스트(List)** 형태입니다.
  * 사용자가 입력하는 상품 번호에서 1을 뺀 값(`pd_idx = user_num - 1`)을 리스트의 인덱스로 사용하여, 해당 인덱스가 상품 데이터의 기본키(Primary Key) 역할을 하도록 구현했습니다.
* **장바구니 관리 (`cart_qty`)**
  * 상품 인덱스(`pd_idx`)를 **키(Key)**로, 담은 수량(`qty`)을 **값(Value)**으로 가지는 **딕셔너리(Dictionary)** 형태입니다.
  * 딕셔너리를 사용함으로써 이미 장바구니에 담긴 상품의 수량을 누적하거나 조회할 때 빠른 탐색이 가능합니다.
* **쿠폰 관리 (`coupon_list`)**
  * `Discount` 클래스를 상속받은 다양한 쿠폰 객체들을 리스트로 묶어 관리합니다. 사용자가 선택한 쿠폰의 인덱스를 저장하여 결제 시 활용합니다.

## 🏛 핵심 클래스 설계

* **`Product` 클래스**
  * 개별 상품의 상태(번호, 이름, 가격, 재고)를 캡슐화하여 관리합니다. 결제 완료 시 이 객체 내부의 `inventory` 값이 직접 변경됩니다.
* **`Discount` (부모 클래스)**
  * 쿠폰의 기본 속성(이름, 할인율, 할인액)과 할인 금액을 계산하는 `discount(total)` 메서드의 기본 틀을 제공합니다. (기본값: 할인 없음)
  * **`RateDiscount` (자식 클래스)**
    * 정률 할인을 제공하며, 메서드 오버라이딩을 통해 '최대 할인 한도' 로직을 구현했습니다. (예: 10% 할인, 최대 5,000원)
  * **`FixedDiscount` (자식 클래스)**
    * 정액 할인을 제공하며, 오버라이딩을 통해 '최소 결제 금액' 조건을 확인하는 로직을 구현했습니다. (예: 20,000원 이상 구매 시 3,000원 할인)

## 🚀 실행 방법

파이썬 환경이 구축된 터미널에서 해당 프로젝트 폴더로 이동한 뒤, 아래 명령어를 입력하여 실행합니다.

```bash
python main.py
```
